# 🔄 数据同步测试指南

## ✅ 数据流工作原理

```
管理后台 → 后端 API → 数据库 (JSON) → 前端自动刷新
```

---

## 🧪 测试步骤

### 测试 1: 添加新课程

1. **打开管理后台：** `http://localhost:5174/`
2. **点击"课程管理"**
3. **点击"新增课程"按钮**
4. **填写课程信息：**
   - 标题：测试课程 123
   - 价格：99
   - 分类：测试分类
   - 描述：这是一个测试课程
   - 封面：上传一张图片（可选）
5. **点击"保存"**
6. **等待 30 秒** 或 **刷新前端页面** `http://localhost:5173/`
7. **✅ 你应该能看到新课程出现在首页！**

---

### 测试 2: 编辑课程

1. **在管理后台点击课程的"编辑"按钮**
2. **修改标题或价格**
3. **点击"保存"**
4. **刷新前端页面**
5. **✅ 修改后的内容会显示在前端！**

---

### 测试 3: 删除课程

1. **在管理后台点击课程的"删除"按钮**
2. **确认删除**
3. **刷新前端页面**
4. **✅ 课程会从前端消失！**

---

### 测试 4: 用户注册 → IP 追踪

1. **打开前端：** `http://localhost:5173/`
2. **点击右上角"登录"**
3. **点击"去注册"**
4. **填写信息并注册**
5. **打开管理后台 → 用户管理**
6. **✅ 你会看到新用户的 IP 地址被记录了！**

---

### 测试 5: 购买课程 → 订单记录

1. **在前端登录账号**
2. **点击任意课程 → "立即订阅"**
3. **选择支付方式 → 确认支付**
4. **打开管理后台 → 控制台**
5. **✅ 你会看到新订单出现在交易记录中！**
6. **✅ GMV 和订单数会自动更新！**

---

## 🔄 数据刷新机制

### 前端自动刷新
- **课程列表：** 每 30 秒自动刷新一次
- **手动刷新：** 刷新浏览器页面（F5）

### 管理后台手动刷新
- **点击"刷新"按钮** 重新加载数据
- **或刷新浏览器页面**

---

## 📊 数据存储位置

所有数据都存储在：
```
ekko-project/server/db/data/
├── courses.json      # 课程数据
├── users.json        # 用户数据（包含 IP）
├── orders.json       # 订单数据
└── activityLogs.json # 活动日志
```

你可以直接打开这些 JSON 文件查看数据！

---

## ✅ 确认数据同步的方法

### 方法 1: 查看 JSON 文件
1. 在管理后台添加课程
2. 打开 `ekko-project/server/db/data/courses.json`
3. 你会看到新课程的数据

### 方法 2: 查看浏览器控制台
1. 打开前端页面
2. 按 F12 打开开发者工具
3. 查看 Network 标签
4. 刷新页面
5. 你会看到 `GET /api/courses` 请求
6. 点击查看响应数据

### 方法 3: 直接访问 API
在浏览器中访问：
- `http://localhost:3001/api/courses` - 查看所有课程
- `http://localhost:3001/api/courses/1` - 查看课程 1

## 💡 如果想要实时更新

如果你想要管理后台一保存，前端立即更新（不等 30 秒），可以：

1. **使用 WebSocket** - 实时推送更新
2. **使用轮询** - 缩短刷新间隔（比如 5 秒）
3. **使用 Server-Sent Events (SSE)** - 服务器推送
