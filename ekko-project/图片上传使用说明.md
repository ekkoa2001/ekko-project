# 📸 课程封面图片上传功能使用说明

## ✅ 已实现的功能

### 1. 后端图片上传 API
- **接口地址：** `POST /api/upload/image`
- **需要权限：** 管理员 Token
- **支持格式：** JPG, PNG, WebP
- **文件大小限制：** 最大 5MB
- **存储位置：** `ekko-project/server/uploads/`
- **访问地址：** `http://localhost:3001/uploads/文件名`

### 2. 管理后台图片上传界面
- 在"课程管理"中点击"新增课程"或"编辑"按钮
- 可以看到"课程封面"上传区域
- 支持拖拽或点击选择图片
- 实时预览上传的图片
- 自动保存图片 URL 到课程数据

---

## 🎯 使用步骤

### 步骤 1: 打开管理后台
访问：`http://localhost:5174/`

### 步骤 2: 进入课程管理
点击左侧菜单的"课程管理"

### 步骤 3: 新增或编辑课程
- 点击"新增课程"按钮
- 或点击现有课程的"编辑"按钮

### 步骤 4: 上传封面图片
1. 在"课程封面"区域点击"选择文件"
2. 选择一张图片（JPG/PNG/WebP，最大5MB）
3. 等待上传完成（会显示"上传中..."）
4. 上传成功后会显示预览图

### 步骤 5: 保存课程
- 填写其他信息（标题、价格、分类、描述）
- 点击"保存"按钮
- 课程封面会自动显示在前端

---

## 📝 示例

### 创建一个新课程：

1. **课程标题：** Shopify 独立站从 0 到 1
2. **价格：** 1299
3. **分类：** 独立站建站

## 🔧 技术细节

### 后端实现
- 使用 `multer` 处理文件上传
- 自动生成唯一文件名（防止冲突）
- 文件类型和大小验证
- 静态文件服务（Express static）

### 前端实现
- FormData 上传文件
- 实时预览功能
- 上传进度提示
- 错误处理

### 存储方式
- 图片存储在：`server/uploads/` 目录
- 文件名格式：`course-时间戳-随机数.jpg`
- 数据库存储完整 URL：`http://localhost:3001/uploads/文件名`

---

## ⚠️ 注意事项

1. **文件大小：** 不要超过 5MB
2. **文件格式：** 只支持图片格式
3. **权限要求：** 需要管理员权限（目前演示模式可以跳过）
4. **生产环境：** 建议使用云存储服务（如阿里云 OSS、AWS S3）

## 📞 遇到问题？

### 上传失败？
- 检查文件大小是否超过 5MB
- 检查文件格式是否正确
- 检查后端服务是否正常运行

### 图片不显示？
- 检查 `server/uploads/` 目录是否存在
- 检查图片 URL 是否正确
- 在浏览器中直接访问图片 URL 测试

### 权限错误？
- 目前演示模式下，token 验证可能会失败
- 可以暂时注释掉 `verifyToken` 和 `verifyAdmin` 中间件进行测试
