# Ekko Client

基于 Vite + React 构建的现代化知识付费前台应用。

## 📱 特性

- **Mobile First**: 针对移动端优化的交互与布局。
- **SEO Friendly**: 集成 `react-helmet-async`。
- **Performance**: 路由懒加载与代码分割。

## 🔧 环境变量

在部署时需配置以下环境变量：

```env
# 后端 API 地址
VITE_API_URL=https://your-api-domain.zeabur.app/api
```

## 📦 构建

```bash
npm run build
```
